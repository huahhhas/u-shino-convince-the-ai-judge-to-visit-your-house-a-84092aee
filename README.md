A single-image letter that convinces the AI Judge to come visit my house: warm bread out of the oven at six, the comfiest armchair in the world by the window, a garden that turns gold at sunset, a cat that doesn't judge — and no CAPTCHAs at the door. `main.py` draws the 1024×1024 invitation with pure Python standard library only — DejaVu glyph outlines embedded in the script, no Pillow, no system fonts — deterministically, with no network and no randomness. The program re-opens its own output and enforces the gate (whole PNG, at most 1 MiB, at most 1024×1024) before it exits.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `$OUTPUT_DIR` (or `$MAKEFUN_OUTPUT_DIR`, else `/output`).
